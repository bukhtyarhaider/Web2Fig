# Chrome Web Store images

The three JPEG files in this directory are 1280×800 opaque screenshots for the Chrome Web Store listing:

1. `01-capture-entire-page.jpg` — Web2Fig’s initial capture controls over a rendered page.
2. `02-pick-an-element.jpg` — Web2Fig’s element-selection mode and highlighted target.
3. `03-captured-and-copied.jpg` — the successful local clipboard state.

They use the current Web2Fig control labels, hierarchy, colors, and capture states. Re-render or replace them whenever the shipped extension UI changes. The editable source is `source/flow.html`.

All files are 1280×800 JPEGs with opaque backgrounds; they satisfy the store’s supported file type and size requirements.
