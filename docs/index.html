Three simple steps

From live interface to design canvas.

Open Web2Fig

Click the extension on any regular webpage.

Choose your scope

Capture the entire page, or select one element with the picker.

Paste into Figma

Use ⌘V on macOS or Ctrl+V on Windows in an open Figma file.

Install

Web2Fig is preparing for the Chrome Web Store.

The public release is currently under review preparation. In the meantime, developers can install the packaged extension from the project repository using Chrome’s “Load unpacked” flow.
