Local Developer Installation

You can test and run Web2Fig locally in Google Chrome using Chrome’s Developer Mode:

TERMINAL 
# 1. Clone the repository
git clone https://github.com/bukhtyarhaider/Web2Fig.git

# 2. Navigate to project folder
cd Web2Fig

1. Open Extensions

Navigate to chrome://extensions in your Chrome browser address bar.

2. Enable Dev Mode

Toggle Developer mode in the top-right corner of the Extensions page.

3. Load Unpacked

Click Load unpacked and select the Web2Fig project directory.
