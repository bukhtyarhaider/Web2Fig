How to use Web2Fig

  1. Open a regular webpage in Chrome and click the Web2Fig toolbar icon.
  2. Choose Capture entire page, or choose Inspect & Pick Element and click the part of the page you need.
  3. Open a Figma canvas and paste with ⌘V (macOS) or Ctrl+V (Windows).

Frequently asked questions

Why can’t I use Web2Fig on a Chrome settings page?

Chrome blocks extensions from running on browser-internal pages such as chrome://, the Chrome Web Store, and some protected pages. Open a normal website instead.

Why are some assets not reproduced exactly?

Some sites restrict cross-origin media, use protected content, draw visuals dynamically, or rely on browser-specific effects. Web2Fig captures what the page exposes to the browser and reports embedded image counts after capture.

Can I capture a local file?

Yes. In chrome://extensions, open Web2Fig’s details and enable “Allow access to file URLs,” then invoke Web2Fig from your local file.

What should I include in a bug report?

Please include the page URL (only if safe to share), the element or page you captured, expected versus actual result, your Chrome version, and any error message. Do not include private page content.

Report an issue

Open a GitHub issue with the details above. Security-sensitive reports should not be posted publicly; contact the maintainer through the email address listed in the Chrome Web Store developer profile once published.
