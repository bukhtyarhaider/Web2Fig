Privacy Policy

Your page stays on your device.

Effective August 14, 2026 · Last updated August 14, 2026

Web2Fig has no accounts, analytics, advertising, cloud storage, or developer-operated servers. It does not sell or share your data.

What Web2Fig processes

Only after you activate Web2Fig, it processes the selected webpage’s DOM structure, displayed text, computed styles, layout information, and visible resources such as images, SVGs, and background assets. This content can include personal or sensitive information if it is present on the page you choose. Processing is necessary to create the Figma-compatible clipboard output you requested.

Where processing happens

Processing occurs locally in the browser. The extension keeps capture data in memory long enough to create the clipboard payload, then does not persist it. Web2Fig does not use browser sync, extension storage, cookies, telemetry, or remote databases.

Images and network requests

To preserve visible cross-origin images and SVGs, Web2Fig may request the same public asset URL directly from its original host after you start a capture. This is a browser request to that host, not a transfer to Web2Fig or a developer-operated service. Web2Fig does not upload captured page content or assets to any Web2Fig server.

Clipboard

When capture completes, Web2Fig writes the resulting Figma-compatible payload to your local system clipboard. Clipboard data is controlled by your operating system and the app where you paste it. Web2Fig does not read it back or retain it.

Permissions

  • activeTab lets Web2Fig operate only in the tab you explicitly activate it on.
  • scripting lets Web2Fig inject its capture and element-selection interface into that active tab.
  • Host access to all URLs is used solely to request cross-origin visual assets needed for the capture you initiated. It is not used for tracking or background browsing.

Sharing, sale, and retention

Web2Fig does not collect, sell, share, retain, or use captured content for advertising, profiling, analytics, or any purpose unrelated to the requested capture. No human at Web2Fig can access your capture because Web2Fig receives no copy.

Changes and contact

If this policy changes, its effective date will be updated here. For questions or privacy requests, open an issue in the Web2Fig GitHub repository.
